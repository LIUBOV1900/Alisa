🐢 Turtle Magic Code

Your fun Python Turtle cheat sheet!
Draw with code. Change numbers. Make magic.
🚀 1. Start
from turtle import *
Bring turtle magic into your code!
Import all turtle commands.
🧩 Like adding the Pen extension in Scratch.
bgcolor("lightblue")
Change the background color 🌈
Background color.
Try: "pink", "yellow", "black", "lightgreen"
🏃 2. Movement
forward(100)
Move forward 100 steps
Go straight ahead.
🧩 Like “move 100 steps” in Scratch.
backward(100)
Move backward 100 steps
Go back.
🧩 Like “move -100 steps” in Scratch.
left(90)
Turn left 90 degrees ↺
Rotate to the left.
🧩 Like “turn left 90 degrees”.
right(90)
Turn right 90 degrees ↻
Rotate to the right.
🧩 Like “turn right 90 degrees”.
goto(100, 100)
Go to a point! Magic teleport 🌟
Go to X and Y coordinates.
🧩 Like “go to x: 100 y: 100”.
💡 X means left/right. Y means up/down.
The center is (0, 0).
🎨 3. Color and Pen
color("red")
Change the line color
Set the turtle and pen color.
Try: "red", "blue", "green", "purple", "orange", "gold"
pensize(5)
Make the line thicker
Pen size = line width.
🧩 Like “set pen size” in Scratch.
Try pensize(1) for a thin line or pensize(10) for a thick line.
penup()
Fly mode ✈️ No drawing!
Lift the pen up.
🧩 Pen Up.
Use it before goto() if you don’t want a line.
pendown()
Drawing mode ✏️ Draw again!
Put the pen down.
🧩 Pen Down.
Use it after penup() when you are ready to draw.
✨ 4. Superpowers
speed(3)
Change drawing speed
Speed from 1 to 10.
1 = slow 🐌
10 = fast 🚀
0 = instant ⚡
circle(50)
Draw a circle ⭕
The number is the radius.
Half-circle: circle(50, 180)
Full circle: circle(50)
hideturtle()
Invisible turtle 🥷
Hide the turtle.
🧩 Like hiding a sprite.
Use it at the end to show only your beautiful drawing.
🎭 5. Creativity
write("Hello!")
Write text on the screen ✍️
Write words with Python.
Text must be inside quotes!

Bigger text:
write("Hi!", font=("Arial", 20, "bold"))
shape("turtle")
Change the turtle shape 🐢
Make your turtle look different.
Try: "turtle", "arrow", "circle", "square", "triangle", "classic"
🎁 6. Fill Shapes
begin_fill()
Start filling a shape 🖌️
Start coloring inside.
💡 First choose a color with color("red"), then draw a shape.
end_fill()
Finish filling a shape ✅
Stop coloring inside.
💡 Use it when your shape is finished.
🏁 7. Finish
exitonclick()
Click the picture to close the window
Exit on click.
Put this at the very end of your code.
mainloop()
Keep the turtle window open
Start the turtle window loop.
Another way to keep the drawing window open.
Usually use exitonclick() or mainloop(), not both.

💡 Pro Tips

1. Commands need parentheses: ()
2. Words need quotes: "red", "Hello!"
3. Numbers do not need quotes: forward(100) ✅, not forward("100") ❌

🎮 Coding is like magic. You just need to know the right words!

🌟 Mini Example: Colorful Square

Try this code. Then change the color, size, and speed!

from turtle import *

bgcolor("lightblue")
shape("turtle")
color("purple")
pensize(5)
speed(3)

begin_fill()
forward(100)
left(90)
forward(100)
left(90)
forward(100)
left(90)
forward(100)
left(90)
end_fill()

penup()
goto(0, 130)
write("My Turtle Art!", font=("Arial", 20, "bold"))
hideturtle()

exitonclick()
