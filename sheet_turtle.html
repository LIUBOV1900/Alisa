🐢 Turtle Quick Reference

🚀 Start & Window

from turtle import * import commands
bgcolor("lightblue") background color
title("My Game") NEW window title
setup(800, 600) NEW window size

🏃 Movement

forward(100) move forward
backward(100) move backward
left(90) turn left
right(90) turn right
goto(x, y) teleport to point
home() NEW return to center (0,0)

🎨 Color & Pen

color("red") set color
pensize(5) line thickness
penup() stop drawing
pendown() start drawing

✨ Special

speed(3) 1=slow, 10=fast
circle(50) draw circle
write("Hi!") write text
hideturtle() hide turtle
shape("turtle") change shape
dot(20, "red") NEW draw a dot
stamp() NEW leave turtle print
undo() NEW undo last action

🧹 Screen Control

clear() NEW erase all drawings
reset() NEW erase all + go home

📍 Coordinates

xcor() NEW current X position
ycor() NEW current Y position
heading() NEW current direction

🎮 For Mini-Games

listen() NEW listen to keys
onkey(func, "Up") NEW key press action
onclick(func) NEW mouse click action

⚡ Speed Up

tracer(0) NEW instant drawing
update() NEW refresh screen

🎁 Fill Shapes

begin_fill() start filling
end_fill() finish filling

🏁 Finish

exitonclick() click to close
💡 Remember: words need quotes "red", numbers don't: forward(100)
🆕 NEW = new commands added today!
