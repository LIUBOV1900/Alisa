✨ NEW STRING SPELLS

s[0], s[2] — Zero-based indexing.
"python"[2] → 't'
s[-1] — Last character.
"dragon"[-1] → 'n'
s[start:stop] — Slice, 'stop' is NOT included.
"treasure"[0:4] → 'trea'
s[::-1] — Reverse the string.
"cat"[::-1] → 'tac'
s.strip().lower() — Chain methods left to right.
" MAGE ".strip().lower() → 'mage'
s.replace("old", "new") — replaces parts of a string.
"frog".replace("fr", "d") → 'dog'
count() + count() — Results can be added.
"abracadabra".count("a") + ... → number
s[1:4].upper() — Slice, then apply method.
"python"[1:4].upper() → 'YTH'
